# My Matplotlib Learning Journey 📊

I started learning Matplotlib to understand how data can be
represented through different types of graphs and charts.

In this Jupyter Notebook, I am practicing different plots
step by step, starting from basic charts and gradually moving
towards more advanced visualizations.

So far, I have practiced:

- Line Plot
- Bar Chart
- Grouped Bar Chart
- Pie Chart
- Histogram
- Scatter Plot
- Box Plot
- Area Plot
- Stem Plot
- Hexbin Plot

I am also learning how to customize graphs using colors,
labels, titles, legends, grids, markers, and other parameters.

This repository represents my **Matplotlib learning journey**,
and I will continue adding more practice as I learn.

**Tools:** Python | Jupyter Notebook | Matplotlib | NumPy

🚀 Learning step by step, one graph at a time.
